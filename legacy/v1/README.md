# Legacy

This directory contains the original Pokémon Companion V1 data pipeline and generated database.

These files are preserved for reference only and are not part of the active architecture.

The active project is developed using:

- `documentation/`
- `scripts/`
- `database/`
- `backend/`
- `frontend/`

When implementing new features, use the documentation as the source of truth.

The contents of this directory may be referenced to reuse algorithms or historical implementations, but they should not define the architecture of the current project.
