# Future Ideas

This document contains ideas that are planned for Pokémon Companion but are not currently scheduled for development.

---

# ✅ Confirmed

These features are planned and will likely be implemented in future releases.

## Screenshot Recognition

Upload a screenshot from a Pokémon game and automatically identify:
- Pokémon
- Location
- Battle information
- UI elements
- Possible objectives

---

## Save File Import

Import save files from supported Pokémon games to automatically populate:

- Pokédex progress
- Team
- Inventory
- Badges
- Story progress
- Play time

---

## Route Heat Map

Visualize which routes and locations have been explored.

Features may include:
- Visited routes
- Missing encounters
- Uncollected items
- Completion percentage

---

## AI Battle Planner

Generate battle recommendations based on:

- Opponent team
- Type matchups
- Available Pokémon
- Movesets
- Items
- Difficulty level

---

## Emulator Setup Guide

Interactive guides for setting up supported Pokémon emulators.

Potential features:

- Emulator recommendations
- BIOS information
- Controller setup
- Save locations
- Performance tips

---

## Battle Replay Analysis

Analyze recorded battles to provide:

- Mistake detection
- Better move suggestions
- Type matchup review
- Win probability insights

---

## Nuzlocke Mode

Dedicated tracker for Nuzlocke challenges.

Possible features:

- Automatic encounter tracking
- Fainted Pokémon log
- Rule enforcement
- Challenge statistics

---

## Professor Oak Challenge

Track progress for Professor Oak's Challenge.

Potential tracking:

- Required Pokédex entries
- Experience grinding
- Evolution checklist
- Completion status

---

# 🔬 Needs Research

These ideas require technical investigation before planning.

## OCR Recognition

Research OCR libraries capable of recognizing:

- Pokémon names
- Stats
- Battle text
- Menus
- UI elements

---

## Automatic Save Detection

Determine whether local save files can be detected automatically across supported emulators and operating systems.

---

## Pokémon HOME Integration

Investigate whether Pokémon HOME offers official APIs or other supported integration methods for importing collection data.

---

## Cloud Synchronization

Research cloud-based synchronization for:

- Progress
- Teams
- Collections
- Settings
- Multiple devices

Potential providers:
- MongoDB Atlas
- Firebase
- Custom backend
