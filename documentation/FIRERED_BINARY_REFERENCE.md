# FireRed Binary Reference

## Purpose

This document records verified technical information about the Pokémon FireRed ROM that is used by Pokémon Companion.

Only verified information should be documented here.

## ROM Information

### Supported ROM

Pokemon - FireRed Version (USA, Europe) (Rev 1).gba

### Game Code

BPRE

### Revision

Revision 1 (Rev 1)

### Region

USA / Europe

### Status

Verified

### Notes

This is the primary FireRed ROM supported by Pokémon Companion.
All binary layouts and extraction logic will initially target this ROM revision.
Additional FireRed revisions may be supported in the future.
